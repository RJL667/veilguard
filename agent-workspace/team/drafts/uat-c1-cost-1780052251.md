# Director Model Cost Analysis: Haiku vs Sonnet

| Model | Input (per 1M tokens) | Output (per 1M tokens) |
|---|---|---|
| Claude 3.5 Haiku | $0.80 | $4.00 |
| Claude 3.5 Sonnet | $3.00 | $15.00 |

*Pricing from Anthropic's published rate card [unverified — research bridge offline].*

A typical Director turn (~500 input / 200 output tokens) costs ~$0.0005 on Haiku vs ~$0.0045 on Sonnet — roughly **9× cheaper**. At 10,000 Director turns per day, Haiku saves ~$40/day.

**Recommendation:** Run the Director on Haiku. Orchestration and task-dispatch work is routing-heavy, not reasoning-heavy; the cost advantage is decisive. Reserve Sonnet for worker agents requiring deep reasoning or complex synthesis.
